# Lightweight Student Registration System

A simple, lightweight Java Web Application created as a learning project to demonstrate the integration of **Java Servlets**, **JSP**, and **MySQL Database**.

## 📌 Project Overview & Workflow
1. **Home Page (`index.html`)**: The landing page welcoming the user with an option to proceed to registration.
2. **Registration Form (`register.html`)**: Allows students to input their details:
   - Full Name
   - Registration Number
   - Email Address
3. **Database Integration**: Form data is processed via a Java Servlet and stored directly into a **MySQL** database.
4. **Data Display (`display.jsp`)**: Retrieves the submitted details and displays them back to the user in a clean table format.

---

## 🛠️ Technologies Used
- **Backend**: Java Servlets, JDBC (Java Database Connectivity)
- **Frontend**: HTML5, JSP (JavaServer Pages)
- **Database**: MySQL
- **Server**: Apache Tomcat
- **IDE**: IntelliJ IDEA
